# Site templates

The content is shared across all templates. To switch the visual shell, edit the
`site_template` value in `_config.yml`, then rebuild or deploy the site.

| Value | Template |
| --- | --- |
| `neural` | Neutral cards with the animated neural field |
| `midnight` | Dark, high-contrast technical design |
| `editorial` | Warm, print-inspired design |
| `ai-portfolio` | Full-bleed AI portfolio with a sticky social header and light/dark mode |
